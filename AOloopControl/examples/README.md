# cacao example configurations

Each directory `<CONFNAME>-conf` is a loop configuration that can be deployed
with `cacao-loop-deploy`. Start with `scexao-vispyr-bin2`. Its README walks
through a full simulated loop.

The list of examples and the full deployment guide are in
[docs/examples.md](../../docs/examples.md).

`archieved-old-donotuse/` holds configurations from older cacao versions. They
don't work with the current scripts.
